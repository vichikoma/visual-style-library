使用说明 ABOUT

文件结构每页独立 HTML，公共样式与脚本在 _assets/base.css 与 _assets/base.js。画面内的元素尺寸统一用容器查询单位（cqw），画框缩放时构图不变形。
图像来源页内画面全部由 HTML / CSS / SVG / Canvas 现场绘制，不引用任何视频截图与外部图片；索引页的缩略图是各页主帧的实际渲染截图（_assets/thumbs/，472×266），可直接作为设计参考或改造成拍摄的分镜稿。
动效说明页面里的循环动效只用于示意节奏（故障闪烁、粒子、图层展开等），并非成片动画；静态截图即为设计稿，系统开启“减少动态效果”时会自动停播。
与风格库的关系样例页依据 视觉风格合集 与 styles/ 下的条目描述制作：概览段与子风格名称、识别要素、AI 创作视觉规则均对应条目内容；提示词一栏是依据条目中的检索标签整理的“要素组合”版，便于直接改写为生成提示。
