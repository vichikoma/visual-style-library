01硬边桌面窗口Hard-edged Desktop Windows

03桌面助手与文字图形Desktop Assistant & Typographic Graphics

紫色助手是稳定视觉锚点，城堡与大字扩展文字的图形作用。表情只靠嘴的形状和眉眼距离区分，形状、圆角、描边保持一致，界面配色不跟着变——同一个角色，在四个镜头里都要一眼认出。

识别要素紫色笑脸黄色通知标签 洋红大字字压窗口

AI 创作视觉规则 RULES & PROMPT

配色与构图米白、黑与淡紫构成底色，洋红和蓝色标记焦点；窗口边界就是构图边界，不额外加光效与渐变。
形体与字体统一硬边边框、标题栏高度和等宽小字；窗口内正文保持阅读层级，大号歌词作为局部强调。
动态用光标、选区和状态变化组织动画——逐字输入、窗口切换、选区移动、文字图形重组，保留桌面操作感。
PROMPT · 要素组合复古桌面界面美学（Retro Desktop GUI Aesthetics），米白内容区、黑色细标题栏、硬边窗口、小型控制按钮与等宽正文，紫色笑脸桌面助手反复出现。洋红粗体大字、蓝色文本选区和黄色小标签突出关键歌词，光标在阅读器、邮件与输入框之间操作。以逐字输入、窗口切换、选区移动和文字图形重组形成动画，保留早期桌面的简洁结构。
